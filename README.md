# 상품 리뷰 감성 분석기

쇼핑몰 리뷰 텍스트를 붙여넣으면 Gemini 기반 에이전트가 **장점/단점 분류 → 감성 점수(1~5점) 산정 → 실제 별점과 비교한 과장 리뷰 리포트**를 만들어 줍니다.

> 수행평가 4 대체 과제 「나를 위한 AI 직원 만들기」 — 주제 ③ 상품 리뷰 감성 분석기

---

## 무엇을 하나요

| 입력 | 출력 |
|---|---|
| 리뷰 원문 텍스트 | 장점 리스트 / 단점 리스트 |
| (선택) 실제 별점 1~5 | 감성 점수 1~5점 + 근거 |
| | 과장 리뷰 여부 리포트 |

## 에이전트가 쓰는 도구 3개

| 도구 | 하는 일 | LLM 호출 |
|---|---|---|
| `classify_review_text` | 리뷰를 장점/단점 문장으로 분류 | O |
| `score_sentiment` | 리뷰 내용만 보고 별점 1~5 추정 | O |
| `detect_review_exaggeration` | 실제 별점 − 감성 점수 괴리 계산 | X (순수 계산) |

## 기술 스택

- **LLM**: Google Gemini API (무료 등급)
- **SDK**: `google-genai`
- **도구 호출**: Gemini Function Calling
- **UI/서버**: Streamlit
